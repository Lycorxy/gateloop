# Admin UI Design v5.0 — 管理系统/B端后台 UI 设计

## 🛑 入口守卫

```
本 Skill 加载后必须按 Step 0→1→...→8 顺序执行全部步骤。
每步播报完成消息，未播报 = 未执行 = 违规。
禁止跳步，禁止用首轮思维直接输出设计。
```

**核心定位：不是"画页面"，而是"按企业设计稿级 Token 系统生成可预测、高效率、零学习成本的 B端 UI"。**

> 🧠 **设计哲学**：像一个资深 B端设计师那样逐步推理——先定设计读确立方向，
> 再选页面类型加载知识，按 Token 编码，每一步都有约束和验证。

核心目标排序：**可预测 > 高效率 > 零学习成本 > 密度合理 > 状态完备**

## Step 1 — 设计读 [低自由度 · 强制]

> **在开始任何设计之前，先输出一行设计读**——这是方向校准，避免设计跑偏。

### 1.1 输出格式

> **"此系统：<角色> 用 <页面类型> 完成 <任务>，预期 <使用频率>，需要 <密度档位>。"**

示例：

- _"此系统：运营人员 用 列表+编辑 管理订单，预期 每天6小时，需要 紧凑密度(48px行高)。"_
- _"此系统：C-level高管 用 Dashboard 看业务概览，预期 每周2次，标准密度。"_

### 1.2 密度档位选择

| 档位     | 表格行高 | 适用场景                     |
| -------- | -------- | ---------------------------- |
| 超密     | 36px     | 日志/审计/大量数据（>500条） |
| **紧凑** | **44px** | **标准列表（推荐默认）**     |
| 标准     | 48px     | 含多信息列的表格             |
| 宽松     | 56px     | 含操作说明/预览的表格        |

> 完成播报：`"✅ Step 1 设计读完成：{角色}/{页面类型}/{密度}"` — 未播报不得进入 Step 2。
>
> 🔒 **强制约束**：此步骤不可跳过。无设计读就编码 = 方向未校准。

├─ 树形+内容                      → 【左右分栏】→ 左树(240-280px) + 右内容(flex:1)

## Step 4 — 按 Token 编码 [低自由度]

> **全部使用 CSS 变量，零硬编码。** 这是 B端设计的基本功。

### 4.1 强制编码规则

```css
/* ✅ 正确：全部使用 CSS 变量 */
background: var(--color-neutral-01, #fff);
border: 1px solid var(--color-neutral-03, #ebebeb);
border-radius: var(--radius-sm, 2px);
color: var(--color-neutral-09, #2b2b2b);
padding: var(--space-16, 16px);
gap: var(--space-8, 8px);

/* ❌ 禁止：硬编码 */
background: #ffffff; /* → var(--color-neutral-01) */
border: 1px solid #eee; /* → var(--color-neutral-03) */
padding: 16px; /* → var(--space-16) */
```

### 4.2 组件尺寸铁律（企业实测值）

| 组件            | 高度                 | 圆角    | 内边距 | 字号     |
| --------------- | -------------------- | ------- | ------ | -------- |
| Primary 按钮    | **40px**             | **2px** | 0 16px | 14px     |
| Line 按钮       | **40px**             | **2px** | 0 16px | 14px     |
| Text 按钮       | auto                 | —       | —      | 14px     |
| 输入框 / Select | **40px**             | **2px** | 0 12px | 14px     |
| 表格行          | **48px**（紧凑44px） | —       | 0 16px | 14px     |
| 表格表头        | **48px**             | —       | 0 16px | 14px/600 |
| 导航菜单项      | **40px**             | —       | 0 20px | 14px/600 |
| 页面标题栏      | **64px**             | —       | 0 24px | 18px/600 |
| 底部操作栏      | **80px**             | —       | —      | —        |

### 4.3 禁止清单

```
□ 硬编码色值          → var(--color-xxx)
□ 硬编码间距          → var(--space-xxx)
□ 按钮/输入框圆角 ≠ 2px → 必须是 --radius-sm
□ 表格全文居中        → 文字左/数字右/状态中/操作右
□ 渐变背景            → 仅顶部导航允许
□ emoji 作图标        → antd icons / lucide-react
□ !important          → 重构选择器
□ z-index > 1000      → 使用定义的层级
□ window.confirm      → Popconfirm
□ Submit 后校验       → On-blur 校验
□ 三列以上表单布局     → 单列或双列
□ Label 在 Input 左侧 → Label 永远在上方
□ Placeholder 替代 Label → 必须有独立 Label
□ 装饰性动效 (>350ms)  → 功能信号仅
□ 彩色 Tag 装饰      → 仅 5 种语义色
```

> 🔒 **强制约束**：硬编码色值/间距 = 违规，必须立即修正。

## Step 5 — 视觉层级系统 [中自由度]

> **B端页面必须建立清晰的视觉层级。** 通过字号 × 字重 × 颜色 × 间距四维控制。

### 5.1 层级定义

| 层级              | 用途                | 字号      | 字重    | 颜色       | 示例         |
| ----------------- | ------------------- | --------- | ------- | ---------- | ------------ |
| **L1 页面标题**   | 内容区大标题        | 18px      | 600     | neutral-10 | "用户管理"   |
| **L2 区块标题**   | 卡片/分组标题       | 16px      | 600     | neutral-10 | "搜索条件"   |
| **L3 表头/Label** | 表格列名、表单标签  | 14px      | 400/600 | neutral-08 | "创建时间"   |
| **L4 正文**       | 表格内容、正文      | 14px      | 400     | neutral-09 | 表格数据     |
| **L5 辅助文字**   | 描述、提示、时间    | 13px/14px | 400     | neutral-06 | "支持中英文" |
| **L6 禁用/占位**  | placeholder、禁用态 | 14px      | 400     | neutral-06 | placeholder  |

### 5.2 层级应用原则

```
同一页面内：
- L1 仅出现 1 次（页面顶部）
- L2 每个 Card/Header 出现 1 次
- L3-L4 是主体内容，重复出现
- L5 用于辅助理解，不可作为主要信息载体
- 通过颜色深浅（neutral-10 → 08 → 06）强化层级
```

### 5.3 信息密度与留白节奏（8pt 网格）

```
页面级间距（从大到小）：
  space-48 (48px)  — 大模块之间
  space-32 (32px)  — 子区域之间
  space-24 (24px)  — 卡片内部区块
  space-16 (16px)  — 页面边距、卡片间距（最常用 ★）
  space-12 (12px)  — 紧凑元素组内
  space-8  (8px)   — 行内元素间距
  space-4  (4px)   — 图标与文字紧贴时

节奏感口诀：「大疏小密，16为基，倍数递进」
```

## Step 6 — 组件组合模式 [中自由度]

### 6.1 列表管理页（70% 的 B端页面）

```
┌──────────────────────────────────────────────────────┐
│  页面标题(L1)              [+Primary] [Line] [Text]  │ ← 工具栏 h:56~64px
├──────────────────────────────────────────────────────┤
│  ┌─ 搜索卡片 ──────────────────────────────────────┐ │
│  │ 条件A[____] 条件B[▼] 条件C[▼] [🔍搜索] [收起]  │ │ ← flex-shrink:0
│  └─────────────────────────────────────────────────┘ │
│  ┌─ 数据表格卡片 ─────────────────────────────────┐  │
│  │  表头(sticky)                                   │  │ ← flex:1
│  │  数据行                                         │  │
│  │  分页                                    < 1 2 > │  │
│  └─────────────────────────────────────────────────┘  │
└──────────────────────────────────────────────────────┘

组合规则：
① 搜索卡片：flex-shrink:0（始终可见，不压缩）
② 表格卡片：flex:1（占据剩余所有空间）
③ 整体用 flex column，不用固定高度
④ 工具栏按钮：每区域 Primary ≤1 / Line ≤2 / Text 不限
⑤ 操作列：≤3个常驻 / >3个 hover浮现
```

### 6.2 Dashboard 页面

```
Dashboard 铁则：
① 一个仪表盘 = 一种决策角色
② KPI 3~5 个，不能再多
③ F 排序：最重要的在左上
④ 图表解释 KPI，不放无关图表
⑤ 表格放最下面用于钻取
```

### 6.3 详情/编辑页

```
字段数量决策树：
  ≤ 6 字段  → Modal（520px 宽）
  7~15 字段 → Drawer（720px 宽）
  > 15 字段 → 独立页（max-width:960px）

表单布局铁律：
  ✅ 单列布局（默认）
  ⚠️ 双列布局（仅限紧密关联字段对）
  ❌ 三列及以上禁止
  ✅ Label 永远在 Input 上方
```

### 6.4 设置页

```
分组卡片 + 底部操作栏(h:80px)
按钮右对齐：取消(左) + 确定(右/Primary)
```

### 7.2 区域级状态

| 区域     | Loading         | Empty               | Error         |

## Step 8 — 自审清单 [低自由度 · 强制]

> **生成完代码后，逐项检查。有任一项不通过则修复后再交付。**

### Token 合规

- [ ] 所有颜色 → `var(--color-xxx, fallback)`，零硬编码
- [ ] 所有间距 → `var(--space-xxx)`
- [ ] 所有圆角 → `var(--radius-xxx)`，按钮/输入框 = `--radius-sm`(2px)

### 尺寸合规

- [ ] 按钮/输入框高度 = 40px
- [ ] 表格行高 = 48px（紧凑44px）
- [ ] 表格表头高度 = 48px，bg = neutral-02，fw = 600
