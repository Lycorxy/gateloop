# 表单设计

---

## 一、表单布局选择

| 字段数 | 布局 | 说明 |
|--------|------|------|
| 1-5 | 单列居中 | 最简洁，max-width: 480px |
| 5-12 | 分组单列 | 用分区标题分组，max-width: 640px |
| 12-20 | 双列 | 相关字段并排，max-width: 800px |
| > 20 | 步骤向导 | 分步完成，每步 ≤ 7 个字段 |
| 设置类 | 左标签右内容 | Label:Input = 1:3 |

---

## 二、表单规范

### 标签位置

| 位置 | 适用 | 优点 | 缺点 |
|------|------|------|------|
| 顶部（推荐） | 通用 | 扫描快、表单窄 | 纵向空间占用 |
| 左侧 | 设置/属性面板 | 节省纵向空间 | 表单更宽 |
| 浮动（内部） | 简短表单 | 美观紧凑 | 辅助工具兼容差 |

**默认选择顶部标签**，除非有明确的空间限制。

### 字段间距

```
Label → Input: 4-8px
Input → Help text: 4px
字段间（纵向）: 16-24px
分组间: 32-40px
最终操作栏上方: 32-48px
```

### 必填/选填标识

```
方案 A（推荐）：必填字段标 * 号（红色）
方案 B：选填字段标"（选填）"后缀
选择依据：必填多 → 用方案 B；选填多 → 用方案 A
```

## 三、表单校验

### 校验时机

| 时机 | 适用 | 体验 |
|------|------|------|
| 实时（onChange） | 格式校验（手机号/邮箱） | 最佳但需 debounce |
| 失焦（onBlur） | 通用校验 | 推荐默认 |
| 提交（onSubmit） | 服务端校验 | 兜底 |

### 错误信息规范

```
✅ "请输入有效的邮箱地址，例如 name@example.com"
❌ "邮箱格式错误"
❌ "字段不能为空"

原则：
1. 告诉用户怎么做对（而非只说哪里错了）
2. 给出示例
3. 红色文字 + error 图标
4. 位置在 Input 正下方（替换 help text）
```

## 四、表单交互

### 条件显示

```
当选择"是"时 → 展开额外字段（带 slideDown 动画 200ms）
当选择"否"时 → 收起并清空已填内容
```

### 步骤向导

```
┌──────────────────────────────────────────┐
│  ● Step 1  ─────  ○ Step 2  ─────  ○ Step 3  │
├──────────────────────────────────────────┤
│                                          │
│  [表单字段...]                            │
│                                          │
├──────────────────────────────────────────┤
│            [上一步]    [下一步 →]          │
└──────────────────────────────────────────┘

规则：
- 每步 ≤ 7 个字段
- 步骤指示器展示完成/当前/未来
- 允许回退到已完成步骤
- 最后一步显示摘要（可选）
```

### 智能默认值

```
1. 基于用户历史：上次填写的值
2. 基于上下文：检测到的时区、语言、位置
3. 基于统计：最常选择的选项
4. 基于关联：选了省份自动筛选城市
```

## 五、表单组件选择

| 输入类型 | 选项数 | 推荐组件 |
|---------|--------|---------|
| 单选 | 2-3 | Radio Group |
| 单选 | 4-8 | Select |
| 单选 | > 8 | Select + 搜索 |
| 多选 | 2-5 | Checkbox Group |
| 多选 | > 5 | Multi-Select / Transfer |
| 是/否 | — | Switch（立即生效）/ Checkbox（提交生效） |
| 数字 | 精确 | Input[type=number] + stepper |
| 数字 | 范围 | Slider |
| 日期 | 单日 | DatePicker |
| 日期 | 范围 | RangePicker |
| 长文本 | — | Textarea（自适应高度） |
| 文件 | — | Upload（拖拽+点击） |

## 六、表单反模式

| 反模式 | 问题 | 修复 |
|--------|------|------|
| 字段太多一次展示 | 用户放弃填写 | 分步/分组/渐进 |
| 所有字段必填 | 用户压力大 | 减少必填项 |
| 提交后刷新页面 | 失败时数据丢失 | AJAX 提交 |
| 无实时校验 | 提交才发现错误 | onBlur 校验 |
| 密码无强度提示 | 不知道如何满足 | 实时强度条 |
| Label 在 Input 内 | 输入后忘记字段名 | Label 在上方 |
| 无法回退 | 向导中不可返回 | 允许回退 |
| Reset 按钮 | 误触清空全部 | 移除 Reset 按钮 |
