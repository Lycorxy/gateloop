# Positive Triggers（应该触发）

## 1. 需求驱动代码生成

```
✅ "根据这个需求生成后端代码"
✅ "这是用户模块的需求文档，帮我生成 tRPC-Go 服务"
✅ "订单模块的需求分析完了，生成后端接口"
✅ "从需求描述生成 Go 后端服务代码"
```

## 2. Proto 文件生成

```
✅ "帮我生成用户的 Proto 文件"
✅ "给订单服务写一份 proto"
✅ "生成商品模块的 protobuf 定义"
✅ "写一个标准的 tRPC proto 文件"
```

## 3. CRUD 后端生成

```
✅ "生成用户表的 CRUD 接口"
✅ "给这张表写增删改查的 Go 代码"
✅ "基于这个 DDL 生成 CRUD 服务"
✅ "生成完整的增删改查后端代码"
```

## 4. 表结构转服务

```
✅ "把这个表结构转成 Go 服务代码"
✅ "根据 MySQL 设计生成对应的 tRPC 接口"
✅ "表建好了，帮我生成后端代码"
```

## 5. 缓存/消息队列代码

```
✅ "这个查询接口需要加 Redis 缓存，帮我生成"
✅ "订单创建后要发 Kafka 消息，生成生产者代码"
✅ "写一个 Kafka 消费者处理订单事件"
✅ "生成带缓存的用户查询接口"
```

## 6. 混合需求

```
✅ "先设计订单表，再生成后端代码"
✅ "用户模块设计完了，proto、service、logic、repo 都生成一下"
✅ "这个需求要支持高并发，帮我设计接口方案然后生成代码"
```

## 7. 明确提到 tRPC-Go

```
✅ "用 tRPC-Go 实现这个功能"
```
