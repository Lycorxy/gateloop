# 布局决策树 + 线框规则

> 从 design-tokens.mdc 提取的布局相关规则，供 frontend-design Skill 专用。

## 布局决策树（遇到新场景必须走这棵树）

```
用户描述的页面是什么类型？
│
├─ 列表管理（增删改查）
│   └─ 标准列表页：顶部搜索卡片(flex-shrink:0) + 下方表格卡片(flex:1)
│       └─ 操作列：编辑(文字按钮) + 删除(文字按钮+Popconfirm)
│
├─ 详情/编辑（单条记录）
│   ├─ 字段 ≤ 6 个 → Modal 弹窗（宽 520px）
│   ├─ 字段 7-15 个 → Drawer 抽屉（宽 720px，从右滑入）
│   └─ 字段 > 15 个 / 有富文本 → 独立详情页（居中卡片 max-width:960px）
│
├─ 树形结构 + 内容（目录+正文）
│   └─ 左右分栏：左侧树(固定宽 240-280px) + 右侧内容(flex:1)
│       └─ 两侧均为卡片三件套，独立滚动（overflow-y: auto）
│
├─ 数据看板（统计/概览）
│   └─ 顶部统计卡片行(flex, gap:16px) + 下方图表/列表区
│
├─ 表单页（配置/设置）
│   └─ 居中卡片(max-width:800px) + 底部操作栏(80px, 按钮右对齐)
│
└─ 混合页（搜索+树+内容）
    └─ 上下两栏：上栏搜索区(flex-shrink:0) + 下栏左右分栏
```

## 组件选型原则

| 场景                | 选用组件                  | 禁止                |
| ------------------- | ------------------------- | ------------------- |
| 数据列表            | antd `Table` / `TTable`   | 自定义 div 列表     |
| 树形目录            | antd `Tree`               | 手写递归 ul/li      |
| 简单选择（≤5 项）   | antd `Radio.Group`        | Select              |
| 简单选择（> 5 项）  | antd `Select`             | Radio               |
| 日期选择            | antd `DatePicker` + dayjs | 原生 input          |
| 富文本/Markdown     | CodeMirror 6              | textarea            |
| 长文本省略          | `TEllipsis`               | CSS overflow:hidden |
| 复杂表单（≥4 字段） | `TForm`                   | 手写 Form.Item      |
| 带搜索的列表页      | `TTable` + `TTableSearch` | 手写搜索逻辑        |

## 线框图生成规则

生成 ASCII 线框时，必须：

1. **先走布局决策树**，确定页面类型
2. **标注精确尺寸**：从 design-tokens.md 取值（如 `左侧树 240px`、`搜索栏 h:40px`）
3. **标注组件选型**：每个区域注明用什么组件
4. **标注交互说明**：hover/选中/空状态如何处理
5. **不生成装饰性元素**：线框只描述结构和功能

## 视觉层级原则

```
层级 1（页面标题）：18px / 600 / neutral-10
层级 2（卡片标题）：16px / 600 / neutral-10
层级 3（正文/表格）：14px / 400 / neutral-09
层级 4（辅助说明）：14px / 400 / neutral-08
层级 5（占位符）：14px / 400 / neutral-06
```

## 反 AI slop 规则

```
❌ 渐变背景卡片（除顶部导航外禁止渐变）
❌ 大量彩色 Tag/Badge 装饰
❌ 每个操作都加图标
❌ 卡片堆叠阴影过重
❌ 表格行高超过 48px
❌ 弹窗宽度超过 720px
❌ 用 emoji 作为图标
❌ 标题字号超过 18px
❌ 按钮圆角超过 4px
```
