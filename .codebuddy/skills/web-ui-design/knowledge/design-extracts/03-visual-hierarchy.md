# 03 — 视觉层级系统

---

## 一、视觉层级的三维度

### 维度 1: 大小

```
主标题: 24-28px (最大，最先被看到)
副标题: 18-20px
正文:   14px (默认阅读尺寸)
辅助:   12px (元数据、时间戳)
微小:   11px (badge、行内注释)
```

### 维度 2: 字重 + 颜色

```
核心信息:  600-700 weight + neutral-09 (最深)
主要信息:  400 weight + neutral-07
次要信息:  400 weight + neutral-06
辅助信息:  400 weight + neutral-05
禁用信息:  400 weight + neutral-04
```

### 维度 3: 空间位置

```
视觉热区（F型扫描）：
┌───────────────────────────┐
│ ████████████████████████  │ ← 第一行（最先看到）
│ ████████████              │ ← 第二行（次之）
│ ████████                  │
│ ████                      │
│ ██                        │ ← 越往下越少关注
└───────────────────────────┘

原则：P0 信息放在左上角和第一行
```

## 二、层级设计规则

### 最多 3 层视觉层级

```
Layer 1（焦点层）: 页面最重要的 1 个元素
  - 大字号/粗体/主色/大面积
  - 用户第一眼看到这里

Layer 2（内容层）: 核心信息和操作
  - 标准字号/标准色/清晰可读
  - 用户 2-5 秒内扫到

Layer 3（辅助层）: 元数据和次要信息
  - 小字号/浅色/紧凑
  - 用户按需查看
```

### 层级实现方法

| 方法 | 效果 | 使用场景 |
|------|------|---------|
| 字号差异 | 强（≥ 4px 差才有效） | 标题 vs 正文 |
| 字重差异 | 中（600 vs 400 明显） | 同尺寸区分强调 |
| 颜色深浅 | 中（至少差 2 级） | 主文字 vs 辅助文字 |
| 留白 | 强（大留白=重要） | 区域分隔 |
| 位置 | 强（左上=核心） | 整体布局 |
| 阴影/层级 | 中（浮起=重要） | 弹层/卡片 |

## 三、信息分级标准

### P0 — 核心信息（必须首屏无操作可见）

```
定义：用户来到这个页面最想看到/操作的东西
示例：
- 列表页的"数据条目"
- 看板的"核心 KPI 数字"
- 表单的"必填字段"
- 工具面板的"当前状态"
```

### P1 — 重要信息（首屏可见或 1 步可达）

```
定义：辅助用户理解或操作 P0 的信息
示例：
- 列表的"筛选条件"
- 数据的"趋势对比"
- 表单的"帮助文字"
- 面板的"操作按钮"
```

### P2 — 次要信息（2 步可达即可）

```
定义：进阶用户或特定场景才需要的信息
示例：
- 列表的"高级筛选"
- 数据的"详细分解"
- 项目的"元数据/创建时间"
- 配置的"不常用选项"
```

### P3 — 可选信息（可隐藏/需手动展开）

```
定义：极少数场景才需要的信息
示例：
- 系统日志
- 原始数据/JSON
- 调试信息
- 变更历史
```

## 四、视觉焦点设计

### 每个页面只有 1 个视觉焦点

```
焦点创建方法：
1. 最大的元素（面积占比 > 40%）
2. 唯一的强色（周围全是中性色）
3. 最大的留白包围
4. 唯一的动态元素

示例：
- Dashboard → 第一个大数字卡片
- 列表页 → 表格本身
- 表单页 → 表单区域（非按钮）
- 空态 → CTA 按钮
```

### 焦点引导路径

```
用户视觉路径应该是：

焦点 → 核心操作 → 次要信息

而不是：

↗ 信息A ↘ 信息B ↗ 按钮 ↘ 信息C（混乱）
```

## 五、密度管理

### Miller 法则（7±2）

一个视图中同时展示的信息组 ≤ 9 个（推荐 5-7）。

```
什么算"一组"：
- 一个卡片 = 1 组
- 一个表格列 = 1 组
- 一组按钮 = 1 组
- 一个图表 = 1 组
- 一段文字 = 1 组

如果超过 9 组 → 必须隐藏/分页/Tab
```

### 密度控制策略

| 策略 | 做法 | 适用 |
|------|------|------|
| 分组 | 用标题/间距/边框分组 | 减少认知负荷 |
| 折叠 | 默认收起，点击展开 | 次要内容 |
| Tab | 内容分类切换 | 平级内容 |
| 分页 | 限制每页数量 | 列表 |
| 渐进 | 先简后详，按需加载 | 详情信息 |
| 缩略 | 显示摘要，详情在 Tooltip/展开 | 长文本 |
