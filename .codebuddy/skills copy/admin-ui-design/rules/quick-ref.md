# B端 UI 设计铁律（一页纸）

> 违反任何一条 = 设计不合格。生成前必查，生成后必验。

---

## 铁律 1 — 色彩禁令

```
❌ 禁止硬编码色值 → 全部 var(--color-xxx)
❌ 禁止渐变背景 → 仅顶部导航例外
❌ 禁止纯黑 #000 / 纯白 #fff 未走 token
❌ 禁止彩色装饰 → 仅语义色（红错/橙警/绿成/蓝主）
唯一强调色：品牌蓝 --color-blue-07 (#1E67FA)
```

---

## 铁律 2 — 间距系统

```
基准：4px，倍数递进
  4px  → 图标与文字间
  8px  → 行内元素、按钮组
 12px → 列表项内边距
 16px → 卡片间距（默认内容区内边距）
 24px → 卡片内边距、模块间距
 32px → 大模块间距
 48px → 页面级间距
❌ 禁止任意奇数间距（5px/7px/13px...）
❌ 禁止 margin/padding 魔法数字
```

---

## 铁律 3 — 圆角规范

```
按钮 / 输入框 / Select  →  2px（--radius-sm），不是4px不是8px
小卡片 / 标签           →  4px（--radius-md）
面板 / 卡片             →  8px（--radius-lg）
大卡片 / 弹窗          → 12px（--radius-xl）
头像 / 图标             → 9999px 圆形
❌ 最常见错误：按钮圆角用了 4px 或 8px → 必须是 2px
```

---

## 铁律 4 — 组件尺寸硬编码

```
按钮高度        = 40px（含文字按钮）
输入框/Select   = 40px
表格行高       = 48px（默认紧凑档）
表格表头       = 48px
导航菜单项     = 40px
左侧导航宽度   = 208px
页面标题栏     = 64px
底部操作栏     = 80px
顶部导航栏     = 60px
❌ 表格行高 ≠ 48px 是第一常见错误
```

---

## 铁律 5 — 字体层级（上限）

```
页面标题 = 18px / 600 / neutral-10  ← 内容区最大字号
卡片标题 = 16px / 600 / neutral-10
正文表格 = 14px / 400 / neutral-09
辅助文字 = 14px / 400 / neutral-08
占位符   = 14px / 400 / neutral-06
全局字体 = PingFang SC, -apple-system, sans-serif
❌ 禁止内容区出现 >18px 的字号
❌ 禁止 <14px 的字号（可访问性）
```

---

## 铁律 6 — 卡片三件套

```
每个卡片必须同时具备以下三项：
  ✅ border: 1px solid var(--color-neutral-03)
  ✅ border-radius: var(--radius-lg)  /* 8px */
  ✅ box-shadow: 0 1px 2px rgba(0,0,0,.05)
缺任何一项 = 不是 B端卡片
```

---

## 铁律 7 — 表格对齐规则

```
文字列  → 左对齐（姓名/标题/描述）
数字列  → 右对齐（金额/数量/百分比/日期时间）
状态列  → 居中（Tag/Badge/开关）
操作列  → 右对齐（按钮组）
❌ 禁止全文居中（最丑陋的B端反模式）
❌ 禁止左对齐数字
```

---

## 铁律 8 — Z-index 层级

```
基础层     = 0   （页面内容）
Sticky    = 10   （粘性表头/侧边栏固定）
Dropdown  = 100  （下拉菜单/选择器浮层）
Overlay   = 500  （遮罩层背景）
Modal     = 501  （弹窗内容，比遮罩高1即可）
Toast     = 600  （消息提示）
Tooltip   = 700  （悬浮提示，最高层）
❌ 禁止 z-index > 1000
❌ 禁止 z-index 无语义递增（每加一层就 +1）
```

---

## 铁律 9 — 全状态覆盖

```
每个交互元素必须实现全部状态：
  元素状态：Default → Hover → Focus → Active → Disabled
  区域状态：Loading(Skeleton) → Empty(设计过空态+CTA) → Error(错误引导)

❌ 禁止只有 Default 状态
❌ 禁止 window.confirm → 用 Popconfirm
❌ 禁止删除无二次确认
```

---

## 铁律 10 — B端特质检查

```
✅ 单屏数据密度 ≥ 15 行（F型扫描区）
✅ 渐进式披露（L1可见→L2 hover→L3点击）
✅ 操作可撤销（危险操作二次确认）
✅ 零装饰（无渐变/发光/模糊背景）
✅ 功能即美学（不过度设计）

❌ C端化倾向（大图大字大间距）
❌ 营销感（渐变/动效过多/emoji）
❌ 信息过载（单屏>7个主要操作入口）
```

## 自审速查清单

```
生成代码后逐条勾选：

【Token 合规】
  □ 所有颜色走 var(--color-xx)
  □ 所有间距走 var(--space-xx)
  □ 所有圆角走 var(--radius-xx)
  □ 无硬编码魔法数字

【尺寸合规】
  □ 按钮/输入框 = 40px 高
  □ 表格行高 = 48px
  □ 按钮/输入框圆角 = 2px
  □ 字号 ≤ 18px（内容区）

【结构合规】
  □ 卡片三件套齐全（border + radius + shadow）
  □ 表格按类型对齐（文左/数右/态中/操右）
  □ z-index 在定义层级内
  □ 无 !important

【状态合规】
  □ hover/focus/disabled 全实现
  □ Loading → Skeleton 非白屏
  □ Empty → 设计空态 + CTA
  □ Error → 错误引导非崩溃

【反AI模式】
  □ 无全文居中表格
  □ 无渐变背景（顶部导航除外）
  □ 无 emoji 作图标
  □ 无 window.confirm
  □ 无 >1000 z-index

【B端特质】
  □ 信息密度足够（非C端稀疏）
  □ 操作路径短（≤3步完成核心任务）
  □ F型扫描友好（重要信息左上）
  □ 零装饰性视觉效果
```
