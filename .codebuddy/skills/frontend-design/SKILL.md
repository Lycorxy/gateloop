## 中断与恢复机制

若执行过程被中断，重新继续时必须：

1. **扫描已有输出** — 检查已完成的 Step 及其完成播报
2. **播报恢复点**：
   ```
   ⏯️ [恢复] 上次进度：X/9 步完成
   已完成：✅ Step 0 — 规则注入 | ✅ Phase 0 — 上下文注入
           ✅ Step 1-3 — 路由/布局/架构 | ✅ Step 3.5 — 模块化
           ✅ Step 3.6 — 耦合分析 | ✅ Step 3.7 — 红线+性能
   待完成：⬜ Step N — {待完成步骤}
   断点：从 Step N 继续
   ```
3. **从断点继续** — 不重复不遗漏
4. **重启确认** — 播报后主动询问用户是否继续

## Phase 0：上下文注入（并行探测）

> 所有设计决策必须基于实际项目上下文，禁止凭空假设。

### 0.1 项目现状探测（并行）

```
list_dir('.codebuddy/skills')
search_files('package.json')            → 定位前端项目根目录
search_files('tsconfig.json')           → 确认 TS 配置

grep_search('path:|Route ', '{项目src}')        → 已有路由
grep_search('create\\(|zustand', '{src}/store')  → Zustand stores
grep_search('export.*const', '{src}/helpers')     → 可复用 helpers
```

### 0.2 设计规范加载（并行）

```
read_file('references/design-tokens.md')          → 本地设计 Token
read_file('references/layout-rules.md')           → 布局规则

// MCP 知识库检索（背景知识有 UUID 时调用）
use_mcp_tool("knowledge", "knowledgebase_search", {
  query:"设计Token 色彩系统 间距 圆角 布局约束",
  keyword:"设计Token;色彩;间距;圆角;布局;尺寸规范",
  knowledge_uuid:"{背景知识UUID}"
})

grep_search('--spacing-|--color-|--radius-', '{src}', '.scss,.css')
```

### 0.3 接口探测

```
涉及后端 → grep_search('export interface', '{src}/types|{src}/api')
           + grep_search('fetch|axios', '{src}/api|{src}/service')
纯前端   → 标记"无后端接口依赖"
```

> 完成播报：`"✅ Phase 0 完成：路由{N}条 Store{K}个 Helpers{J}个 Token已加载"`

## 执行步骤

### Step 1：路由冲突检查 → Step 2：布局决策 → Step 3：架构决策

```
遵循已注入的铁律 1（布局决策树）、铁律 2（架构决策）进行设计。
路由/数据流/组件拆分/页面路径 全部在此步骤确定。
```

### Step 3.5：📦 模块化设计

```
遵循已注入的铁律 3（模块化设计）：
  输出：模块列表 + 目录结构 + 拆分决策 + 接口原则 + 依赖声明
```

### Step 3.6：🔗 耦合分析

```
遵循已注入的铁律 4（耦合分析）：
  输出：耦合分析报告（评分矩阵 + 健康度判定）
  出现死耦合（≥7分）或循环依赖 → 回退 Step 3.5 重新设计
```

### Step 3.7：🔒 红线边界 + 性能策略

```
遵循已注入的铁律 5：输出红线文件清单 + 性能策略决策
```

### Step 3.8：🔗 兼容性策略

```
遵循已注入的铁律 6：输出浏览器目标 + CSS安全/禁止特性 + 降级方案
```

### Step 3.9：🛡️ 交互兜底

```
遵循已注入的铁律 7：输出交互7态矩阵 + 数据5态矩阵 + 防呆规则
```

### Step 3.10：🔧 技术选型

```
遵循已注入的铁律 8：遍历 6 棵决策树，输出每项选型结果
```

### Step 4：ASCII 线框（强制）

```
遵循已注入的铁律 9（线框图规则）：
  用 ┌─┐│└┘├┤┬┴┼ 输出线框图 + 标注尺寸/组件/交互 + 强制约束声明
```

### Step 5：🔒 人工关卡1（强制）

```
展示线框图，等待用户确认（A确认 / B调整最多2次 / C重做）
```

### Step 6：写入出参

```
current.json → { "frontendPlan": {...} }
task-queue.json → status → "done"
```
