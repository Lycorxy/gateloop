# 页面模板

---

## 一、列表管理页（最常用）

```
┌─────────────────────────────────────────────────────────┐
│ 页面标题                              [+ 新建]           │
├─────────────────────────────────────────────────────────┤
│ [全部(128)] [进行中(42)] [已完成(86)]                    │  ← 快捷筛选 Tab
├─────────────────────────────────────────────────────────┤
│ [🔍 搜索...]  [状态 ▼] [日期 ▼]  [重置] │ 共 128 条     │  ← 筛选栏
├────┬──────────────────────────────────┬───────┬─────────┤
│ □  │ 名称 ↕                          │ 状态  │ 操作    │  ← 表头
├────┼──────────────────────────────────┼───────┼─────────┤
│ □  │ Item 1                          │ ● 活跃│ [编辑]  │
│ □  │ Item 2                          │ ○ 草稿│ [编辑]  │
│ □  │ Item 3                          │ ● 活跃│ [编辑]  │
├────┴──────────────────────────────────┴───────┴─────────┤
│           ‹ 1 2 3 ... 13 ›        10条/页 ▼             │  ← 分页
└─────────────────────────────────────────────────────────┘
```

### 关键设计点
- 页面标题左对齐，主操作按钮右对齐
- 快捷筛选用 Tab（≤ 5 个常用状态）
- 高级筛选用 Dropdown（不常用条件）
- 表格操作列固定右侧
- 批量操作：勾选后顶部出现操作栏

## 二、详情页

```
┌─────────────────────────────────────────────────────────┐
│ ← 返回列表    项目名称                [编辑] [删除]      │  ← 面包屑+操作
├─────────────────────────────────────────────────────────┤
│ [概览] [配置] [日志] [成员]                              │  ← Tab 导航
├──────────────────────────────────┬──────────────────────┤
│                                  │ 属性                  │
│  主要内容区                       │ 状态: ● 运行中        │
│                                  │ 创建: 2024-01-15     │
│  - 描述                          │ 负责人: @张三         │
│  - 图表/统计                     │ 标签: [前端] [P1]     │
│  - 子表格/时间线                  │                      │
│                                  │ 快捷操作              │
│                                  │ [重启] [暂停]         │
├──────────────────────────────────┴──────────────────────┤
│ 相关资源 / 活动记录                                      │
└─────────────────────────────────────────────────────────┘
```

### 关键设计点
- 主内容区 60-70%，属性栏 30-40%
- Tab 切换内容区，属性栏始终可见
- 属性栏信息精简，详细属性点击后展开
- 操作按钮在标题栏右侧

- 时间筛选器全局影响所有图表
- 自动刷新 + 最后更新时间

## 六、工具面板（如本项目 Lynx 面板）

```
┌─────────────────────────────────────────────────────────┐
│ 🦊 Lynx     [录制] [网络] [Mock]    [📌] [—]           │  ← 可拖拽头部
├─────────────────────────────────────────────────────────┤
│                                                         │
│  当前 Tab 内容                                          │
│                                                         │
│  - 紧凑布局（工具属性，非阅读内容）                      │
│  - 操作按钮紧凑排列                                     │
│  - 列表可滚动                                           │
│                                                         │
├─────────────────────────────────────────────────────────┤
│ ◢ 缩放手柄                                              │
└─────────────────────────────────────────────────────────┘
```

### 关键设计点
- 浮动面板：可拖拽 + 可缩放 + 可固定
- 收起态：仅 FAB 按钮（48×48）
- Tab 用于功能模块切换
- 内容区紧凑，适合工具型
- 间距比常规页面小（用 8-12px 而非 16-24px）
- 字号比常规小 1 级（12-13px）
