# 05 — 交互与状态

> 来源：taste-skill §4.5-4.6 + ui-ux-pro-max + redesign-skill

## UI状态完全覆盖

AI 默认只生成静态成功态。必须实现完整循环：

| 状态 | 要求 |
|------|------|
| **Loading** | Skeleton 骨架屏（匹配最终布局形状），不用通用圆形 spinner |
| **Empty** | 精美编排的空态，指示如何填充 |
| **Error** | 清晰内联错误（表单）或上下文提示（toast仅用于瞬态） |
| **Success** | 静默确认，不弹窗 |
| **Active** | `scale-[0.98]` 或 `-translate-y-[1px]` 模拟物理按压 |
| **Focus** | 可见的焦点环（必须，不可移除） |
| **Hover** | 150ms 内响应，背景位移/缩放/平移 |
| **Disabled** | 灰色不可点击，有视觉区分 |

## 交互规则

### 触控
- 最小触控区 44×44px
- 触控目标间距 ≥ 8px
- 禁止仅依赖 hover（触屏不可用）

### 按钮
- 加载中时禁用按钮 + 显示 spinner
- 文字对比度必须通过 WCAG AA（4.5:1 正文，3:1 大文字 18px+）
- CTA 按钮文字桌面端单行，禁止换行
- 一页内同一意图的 CTA 只用一个标签
- 同一页不允许 "联系我们" + "开始对话" + "发起项目" 同时存在

### 反馈
- 操作反馈 < 300ms
- 触觉反馈用于确认和重要操作
- Toast 仅用于瞬态（"已保存"），非关键错误用内联

## 辅助功能（按优先级）

1. **对比度** — 4.5:1（正文），3:1（大文字）
2. **焦点环** — 可见焦点指示器 2-4px
3. **Alt 文本** — 有意义的图片描述
4. **Aria 标签** — 纯图标按钮必须 aria-label
5. **键盘导航** — Tab 顺序 = 视觉顺序
6. **跳过链接** — 跳到主内容
7. **标题层级** — h1→h6 顺序，不跳级
8. **不限颜色传递信息** — 必须 + 图标/文字辅助
9. **减少动效** — 尊重 `prefers-reduced-motion`
10. **表单标签** — Label 在输入框上面，禁止 placeholder 替代 label

## 表单模式

```
Label
[Input]
Helper text (可选)
Error text (内联，红色)
```

- 校验：on-blur 校验，不是 submit 后才校验
- 错误信息在问题字段附近，不在页面顶部
- 表单对比度检查：placeholder、焦点环、helper、error 全部通过 WCAG AA

## 数据表格

| 规则 | 要求 |
|------|------|
| 对齐 | 文字左对齐，数字右对齐 |
| 行高 | 44-48px |
| 表头 | 粘性，不随滚动消失 |
| 分页 | 底部固定，页码可点击 |
| 空态 | 设计过的空态，不显示空格子 |
| 排序 | 可排序列有视觉提示 |
