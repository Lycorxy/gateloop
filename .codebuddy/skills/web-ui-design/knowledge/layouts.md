# 布局模式详解

---

## 一、布局选择决策树

```
你的页面核心用途是什么？
│
├── 数据展示（看板/报表）
│   ├── 数据 ≤ 4 个 KPI → 顶部 Stat Cards + 下方 Chart
│   ├── 多维度对比 → Grid 布局（2-4 列 Cards）
│   └── 实时监控 → 固定布局 + 数据自动刷新
│
├── 数据管理（CRUD）
│   ├── 单一类型 → 顶部筛选栏 + 表格 + 底部分页
│   ├── 多类型 → Tab + 各 Tab 内独立表格
│   └── 层级关系 → Master-Detail（左列表 + 右详情）
│
├── 内容编辑（表单/编辑器）
│   ├── ≤ 5 字段 → 单列居中表单
│   ├── 5-15 字段 → 分组表单（分区标题）
│   ├── > 15 字段 → 步骤向导 / 多 Tab
│   └── 富内容编辑 → 编辑器 + 侧边属性栏
│
├── 工具操作（调试/配置）
│   ├── 多面板 → 可拖拽/可缩放分栏
│   ├── 命令行 → 终端 + 输出面板
│   └── 可视化配置 → 画布 + 属性面板
│
└── 信息浏览（文档/列表）
    ├── 长文档 → 侧边 TOC + 主内容
    ├── 卡片式 → Masonry / Grid
    └── 时间线 → Timeline 纵向流
```

## 二、经典布局模式

### 1. 圣杯布局（最通用的管理系统）

```
┌─────────────────────────────────────────────┐
│ Header (56px)                                │
├────────┬────────────────────────────────────┤
│        │ Toolbar / Breadcrumb (48px)        │
│ Side   ├────────────────────────────────────┤
│ (240px)│                                    │
│        │         Main Content               │
│        │                                    │
│        │                                    │
│        ├────────────────────────────────────┤
│        │ Footer / Pagination                │
└────────┴────────────────────────────────────┘
```

**适用**：后台管理系统、SaaS 产品、企业应用
**关键参数**：
- 侧栏：240px（展开）/ 64px（收起）
- 头部：56px 固定
- 主区域：`calc(100vw - 240px)` 自适应
- 内容内边距：24-32px

### 2. Master-Detail（列表+详情）

```
┌─────────────────────────────────────────────┐
│ Header                                       │
├──────────────┬──────────────────────────────┤
│              │                              │
│  List/Tree   │       Detail Panel           │
│  (30-40%)    │       (60-70%)               │
│              │                              │
│  [Item 1]  ←→│  Title                      │
│  [Item 2]    │  Properties...              │
│  [Item 3]    │  Content...                 │
│              │                              │
└──────────────┴──────────────────────────────┘
```

**适用**：邮件客户端、文件管理、消息系统、配置管理
**关键参数**：
- 列表宽度：280-400px 或 30-40%
- 分割线：1px neutral-03
- 选中高亮：主色背景 8% 透明度

### 3. Dashboard Grid（数据看板）

```
┌─────────────────────────────────────────────┐
│ [Stat 1] [Stat 2] [Stat 3] [Stat 4]        │
├─────────────────────┬───────────────────────┤
│                     │                       │
│   Chart (Large)     │   Chart (Small)       │
│                     │                       │
├─────────────────────┼───────────────────────┤
│                     │                       │
│   Table             │   Activity Feed       │
│                     │                       │
└─────────────────────┴───────────────────────┘
```

**适用**：数据分析、运营看板、监控系统
**关键参数**：
- Grid gap：16-24px
- Stat Card 高度：80-100px
- Chart 区域高度：240-360px
- 响应式：< 1200px 折叠为单列

### 4. 工具面板布局（IDE 风格）

```
┌─────────────────────────────────────────────┐
│ Toolbar (44px)                               │
├────────┬─────────────────────────┬──────────┤
│        │                         │          │
│ Panel  │   Main Canvas /         │ Property │
│ Left   │   Editor                │ Panel    │
│ (可折叠)│                         │ (可折叠)  │
│        │                         │          │
├────────┴─────────────────────────┴──────────┤
│ Bottom Panel (可折叠, 120-240px)              │
└─────────────────────────────────────────────┘
```

**适用**：代码编辑器、设计工具、调试面板、可视化编排
**关键参数**：
- 面板可拖拽调整宽度
- 最小宽度约束防止内容塌缩
- 面板折叠后只显示图标列（36-48px）

## 三、布局质量评估标准

| 维度 | 优秀 (9-10) | 良好 (7-8) | 及格 (5-6) | 不及格 (<5) |
|------|-----------|-----------|-----------|------------|
| 信息直达 | P0 无需操作即可见 | P0 需 1 次操作 | P0 需滚动 | P0 被隐藏 |
| 视觉焦点 | 1 个明确焦点 | 2 个焦点有主次 | 多焦点竞争 | 无焦点/全平 |
| 空间效率 | 无浪费+有节奏 | 略有空白 | 大块空白 | 拥挤或荒芜 |
| 可扩展 | 增删内容不需重构 | 小调整即可 | 需要改结构 | 完全刚性 |
| 一致性 | 间距/对齐完美 | 1-2 处偏差 | 多处不一致 | 混乱 |

## 四、响应式断点

| 断点 | 宽度 | 布局调整 |
|------|------|---------|
| Desktop L | ≥ 1440px | 完整多栏 |
| Desktop | 1024-1439px | 侧栏可收起 |
| Tablet | 768-1023px | 侧栏 overlay |
| Mobile | < 768px | 单列 + 底部导航 |

## 五、常见布局反模式

| 反模式 | 问题 | 修复 |
|--------|------|------|
| 无限滚动无锚点 | 找不到之前看的内容 | 加分页/锚点/回到顶部 |
| 侧栏放不相关内容 | 干扰主线任务 | 侧栏只放导航/属性 |
| 内容区过宽 | 阅读困难(>80字/行) | max-width 约束 |
| 等高等宽三卡片 | 无层级、无重点 | 主卡大、次卡小 |
| 多级 Tab 嵌套 | 迷失位置 | ≤ 2 层 Tab |
