# 分工判定表（命令验收 vs 理解判断）

## 5 类细分

| 类 | 判定 | 本 skill 中的对应 | 落地方式 |
|---|---|---|---|
| **A 收敛型** | 有固定命令/CLI，exit code 即结论 | flowcli/gitflow 每条命令执行成败 | 执行后查 exit code + 关键输出行（准确 100%） |
| **B 完备型** | 结构/字段完整性可校验 | 方案完整性（场景+步骤+验收点+危险标注） | Step 2 播报时对话内自检 |
| **C 度量型** | 数值阈值 | 无（本 skill 无量化指标） | — |
| **D 主观理解型** | 需要模型理解判断 | 场景与用户问题匹配？命令语法与 references 一致？结论带证据？ | 对话内逐条核对（验证清单） |
| **E 纯审美型** | 无对错 | 输出排版风格 | 不管 |

## 分流结论（本 skill）

- **命令执行验收：全部 A 类 → exit code + 关键输出行**，准确 100%，不依赖模型自评。
- **方案与结论核对：D 类 → 对话内按验证清单逐条核对**，不落盘文件。
- 无 C/E 类项，不配度量与审美评审。
