# 07 — 反模式清单（Design Audit Checklist）

---

## 一、布局反模式

| # | 反模式 | 问题 | 修复方案 |
|---|--------|------|---------|
| 1 | 三等高卡片 | 无层级、无重点 | 主卡大 + 次卡小 或不等分 |
| 2 | 全宽表格无约束 | 2560px 屏幕上行太长 | max-width 1400px + 居中 |
| 3 | 多层 Tab 嵌套 | 用户迷失位置 | ≤ 2 层 Tab |
| 4 | 空白 ≥ 内容面积 | 浪费空间 | 合理密度 + 留白有节奏 |
| 5 | 侧栏放非导航内容 | 干扰主线 | 侧栏仅放导航/属性 |
| 6 | 无内容宽度限制 | 阅读困难 | max-width 约束 |
| 7 | 内容区域不对齐 | 视觉混乱 | 统一网格系统 |

---

## 二、交互反模式

| # | 反模式 | 问题 | 修复方案 |
|---|--------|------|---------|
| 1 | 一切弹 Modal | 过度打断 | 仅破坏性/重要操作用 Modal |
| 2 | 操作无反馈 | 用户不确定是否生效 | Toast/状态变化/动效 |
| 3 | 自动关闭过快 | 来不及读 | ≥ 3s 或手动关闭 |
| 4 | 隐藏 P0 操作 | 关键功能找不到 | P0 始终可见 |
| 5 | 全部字段必填 | 用户压力大 | 减少必填项 |
| 6 | 无 Loading 态 | 不知道在等什么 | Skeleton + 进度 |
| 7 | 表单提交后刷新 | 数据丢失风险 | AJAX 无刷新 |
| 8 | 步骤不可回退 | 用户被困 | 允许返回上一步 |
| 9 | 过度确认 | 每步都问"确定？" | 仅不可逆操作确认 |
| 10 | 功能靠文字说明 | 不直觉 | 组件本身传达功能 |

---

## 三、视觉反模式

| # | 反模式 | 问题 | 修复方案 |
|---|--------|------|---------|
| 1 | AI 紫渐变 #667eea→#764ba2 | 千篇一律 | 选择有品牌感的独特主色 |
| 2 | 到处用 box-shadow | 页面像漂浮的碎片 | 仅弹层/卡片用 |
| 3 | 全局 glass-morphism | 可读性差 + 性能差 | 仅 overlay 用 |
| 4 | 所有按钮同色 | 无操作层级 | Primary/Secondary/Tertiary |
| 5 | 纯灰底白卡片 | 无特色 | 加签名元素 |
| 6 | 间距不统一 | 视觉混乱 | 严格 4px 网格 |
| 7 | 字重滥用 bold | 全是重点=没有重点 | 仅标题 600+，正文 400 |
| 8 | 过大圆角 | 幼稚感 | 按钮 ≤ 8px，卡片 ≤ 12px |
| 9 | 渐变大面积背景 | 2018 过时审美 | 纯色或极微妙渐变 |
| 10 | 花哨 border（虚线/双线/彩色） | 降低品质感 | 1px solid neutral-03 |

---

## 四、色彩反模式

| # | 反模式 | 修复 |
|---|--------|------|
| 1 | 主色面积 > 10% | 克制到 3-5% |
| 2 | 同时用 > 3 种色相 | 1 主色 + 中性色 + 语义色 |
| 3 | 硬编码 hex 值 | 全部用 CSS Variable |
| 4 | 文字色对比度不足 | 遵循 WCAG AA (4.5:1) |
| 5 | 红/绿同时用于状态 | 色盲友好：加图标/形状区分 |
| 6 | 深色背景上用低饱和色 | 确保 contrast ratio |

---

## 五、间距反模式

| # | 反模式 | 修复 |
|---|--------|------|
| 1 | Magic number (7px, 13px, 15px) | 只用 4 的倍数 |
| 2 | 内部间距 > 外部间距 | 反直觉：内 < 间 < 组 < 区 |
| 3 | 全部相同间距 | 无层级感：加入疏密节奏 |
| 4 | 负间距修复布局 | 结构问题：修正 HTML 结构 |
| 5 | padding 和 margin 混用不一致 | 统一策略 |

---

## 六、排版反模式

| # | 反模式 | 修复 |
|---|--------|------|
| 1 | 全页面一种字号 | 至少 3 层：标题/正文/辅助 |
| 2 | 行高 < 1.4 | 正文 1.5-1.6，标题 1.3 |
| 3 | 段落每行 > 80 字符 | max-width 约束到 65-75 字符 |
| 4 | 中文用纯 sans-serif | 加 PingFang/Microsoft YaHei |
| 5 | 字号 < 12px 大面积使用 | 12px 为可读性下限 |

---

## 七、状态反模式

| # | 反模式 | 修复 |
|---|--------|------|
| 1 | 无空态 | 插图 + 文案 + CTA |
| 2 | Loading 用大 Spinner | Skeleton 骨架屏 |
| 3 | 错误只说"出错了" | 说明原因 + 如何修复 |
| 4 | Disabled 不解释原因 | Tooltip 说明为何不可用 |
| 5 | 成功/失败无区分 | 颜色 + 图标 + 文案 |

---

## 八、性能反模式

| # | 反模式 | 修复 |
|---|--------|------|
| 1 | 大图片无 lazy load | 首屏外图片 loading="lazy" |
| 2 | 动画用 top/left 触发重排 | 用 transform |
| 3 | 大列表无虚拟化 | > 100 项用虚拟滚动 |
| 4 | 每个 hover 触发网络请求 | 预取或延迟触发 |
| 5 | CSS 动画无 will-change | 给动画元素 will-change |

---

## 九、自动审计脚本（检测思路）

```
审计步骤：
1. 提取所有 margin/padding/gap 值 → 检查是否为 4 的倍数
2. 提取所有颜色值 → 检查是否来自 Token
3. 计算 box-shadow 出现次数 → 是否过多
4. 检查 border-radius 值 → 是否一致
5. 检查按钮层级 → Primary 数量 ≤ 1
6. 检查 font-weight → 仅标题 600+
7. 检查 :hover/:active/:focus → 是否全覆盖
8. 检查空态组件 → 是否有兜底
```
