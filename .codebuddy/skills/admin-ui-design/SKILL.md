## Step 4 — Token 编码

参照 `RULE.mdc` 的以下章节编码，**禁止硬编码**：

- **[色彩系统]** — 中性色/品牌蓝/语义色，全部 `var(--color-xxx)`
- **[间距系统]** — 4px 基准，全部 `var(--space-xxx)`
- **[圆角系统]** — 按钮/输入框 = 2px (`--radius-sm`)，卡片 = 8px (`--radius-lg`)
- **[组件精确规格]** — 按钮 40px / 表格行 48px / 输入框 40px

> 🔒 硬编码色值/间距 = 违规，立即修正。

## Step 6 — 组件组合

### 列表管理页（70% 的 B端页面）

搜索区 `flex-shrink:0` + 表格区 `flex:1` / 工具栏 Primary≤1 / 操作列≤3 常驻

### 详情/编辑页

≤6字段→Modal(520px) / 7-15→Drawer(720px) / >15→独立页 | 底部按钮右对齐

### Dashboard

一种角色一个看板 / KPI 3-5 个 / F 排序（最重要左上）

### 设置页

分组卡片 + 底部操作栏(80px) / 按钮右对齐

---

## Step 7 — 状态覆盖

参照 `RULE.mdc` **[交互状态]** 章节：

```
元素态：Default → Hover(bg:blue-01) → Focus(outline:blue-07) → Disabled(opacity:.5)
数据态：Loading(Skeleton) → Empty(插画+CTA) → Error(引导)
删除：Popconfirm（禁 window.confirm）
动效：hover 120ms / 状态切换 150ms / 展开收起 200ms
```

## Step 8 — 自审清单 [强制]

对照 `rules/quick-ref.md` 的**[自审速查清单]**逐项检查：

```
□ Token合规（颜色/间距/圆角全 var）   □ 尺寸合规（按钮40px/行高48px/圆角2px）
□ 结构合规（卡片三件套/表格对齐）     □ 状态合规（hover/focus/disabled 全覆盖）
□ 反AI模式（无emoji/无渐变/无!important） □ B端特质（信息密度/零装饰）
```

> **验证检查点：**
> ```
> □ 6 项自审全部通过 | □ 无硬编码 | □ 无!important
> □ 表格对齐正确 | □ 状态全覆盖
> ```
