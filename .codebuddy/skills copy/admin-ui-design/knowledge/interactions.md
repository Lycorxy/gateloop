## 一、Command Palette（Cmd+K）

### 参考：Linear Cmd+K（行业标准）

```
触发：Cmd+K (Mac) / Ctrl+K (Windows) + 顶部搜索图标

┌────────────────────────────────────────────────────┐
│ Cmd+K                                             │
│ > 搜索项目、命令或跳转...                          │
│                                                    │
│   最近访问                                          │
│   ├─ FE-142  修复导航动画        ↵ 打开            │
│   ├─ 设置页  系统配置           ↵ 跳转            │
│                                                    │
│   常用命令                                          │
│   ├─ C  创建新项目                                  │
│   ├─ /  打开全局搜索                                │
│   ├─ T  切换主题                                    │
│   └─ ?  查看所有快捷键                               │
│                                                    │
│   导航                                              │
│   ├─ → 项目管理                                     │
│   ├─ → 用户中心                                     │
│   └─ → 系统设置                                     │
└────────────────────────────────────────────────────┘

特点：
- 模糊搜索（fuzzy search）
- 最近访问记录
- 快捷键提示（mnemonic: C=Create, T=Theme）
- 不离开键盘即可完成任何操作
```

## 二、Optimistic UI（乐观更新）

### 更新模式对比

```
传统模式（慢）：
[用户点击保存] → [显示 Loading] → [请求 API] → [等待响应] → [更新 UI]

Optimistic UI（快）：
[用户点击保存] → [立即更新 UI 为成功态] → [后台静默同步] → [失败才回滚]
```

### 适用场景

```
✅ 适用：
- 标记已读/未读
- 切换开关（Switch）
- 拖拽排序
- 简单字段编辑
- 点赞/收藏

❌ 不适用：
- 涉及金钱的操作
- 不可逆操作（删除——需二次确认）
- 强依赖服务端验证的操作
```

## 三、内联编辑（Inline Editing）

```
触发：双击单元格 / 点击编辑图标 / 行内 Edit 按钮

┌─────────────────────────────────────────────┐
│  项目名称          │ 状态    │ 操作          │
│  My Project ██████ │ ●运行中  │ ✓ ✕          │  ← 编辑态
│  └─────────────────┘         │               │
│                    [取消] [保存] │               │
└─────────────────────────────────────────────┘

规则：
- Enter 保存，Esc 取消
- 失焦自动保存（可选）
- 保存时显示微型 loading spinner
- 失败时原值恢复 + toast 提示
- 仅适用于简单文本/数字/Select 字段
- 复杂字段仍用 Modal/Drawer
```

## 四、批量操作（Bulk Actions）

```
触发：勾选 ≥ 1 行后，表格上方出现批量操作栏

┌──────────────────────────────────────────────────┐
│ 已选择 3 项        [全部取消]  [导出] [删除] [···] │  ← 浮动操作栏
├──────────────────────────────────────────────────┤
│ □ ☑ Name A  ...                                   │
│ □ ☑ Name B  ...                                   │
│ □ ☑ Name C  ...                                   │
│ □ ☐ Name D  ...                                   │
└──────────────────────────────────────────────────┘

批量操作类型：
- 批量导出（CSV/Excel）
- 批量删除（需二次确认 Modal）
- 批量修改状态
- 批量移动/分类
- 批量标签

来源：0xMinds — "Bulk action toolbar with deactivate, delete, and export CSV buttons"
```

## 五、快捷键体系

```
全局快捷键：
  Cmd/Ctrl + K    Command Palette
  Cmd/Ctrl + /    搜索
  Cmd/Ctrl + B    侧边栏切换
  Cmd/Ctrl + ,    设置

列表页快捷键：
  ↑↓              上下移动选中行
  Space           切换当前行选中
  E               编辑当前行
  Enter           打开当前行详情
  Delete          删除当前行（需确认）

表单快捷键：
  Cmd/Ctrl + Enter  提交表单
  Esc               取消/关闭
  Tab               下一个字段
  Shift + Tab       上一个字段
```

## 六、拖拽排序

```
适用场景：
- 列表项排序
- 看板卡片移动
- 导航菜单排序
- 优先级调整

实现要点：
- 拖拽手柄（⋮⋮ 图标）在行左侧
- 拖拽时行半透明 + 阴影提升
- 目标位置显示蓝色插入线
- 放下后 Optimistic UI 更新
- 失败时回滚 + toast 提示
```

## 七、筛选与搜索

### 搜索模式

```
1. 全局搜索（Cmd+K）
   - 模糊搜索
   - 跨模块搜索
   - 最近访问

2. 列表页搜索
   - 顶部搜索框
   - 支持关键词 + 条件组合
   - 可折叠筛选区域

3. 列内搜索
   - 表头点击筛选图标
   - 下拉选择/输入搜索
   - 适用于枚举类型列
```

### 筛选器设计

```
┌────────────────────────────────────────────────────┐
│ 关键词 [________] 状态[▼全部] 类型[▼全部] 时间[▼]  │
│                                                    │
│ 已选筛选：[×运行中] [×最近7天]    [清除全部]        │
└────────────────────────────────────────────────────┘

规则：
- 筛选项 ≥ 4 个时，默认折叠，点击"展开筛选"
- 已选筛选条件以 Tag 形式展示在搜索框下方
- 提供"清除全部"一键重置
- 筛选结果实时更新（不需要点"搜索"按钮）
```

## 八、确认与反馈

### 确认模式选择

```
操作类型              │ 确认方式
─────────────────────┼──────────────
不可逆操作（删除）     │ Modal 二次确认
批量操作（> 1 条）    │ Modal 二次确认
简单切换（开关）       │ 无需确认 + Toast
表单提交              │ 无需确认 + Toast
导航离开未保存表单     │ 警告提示
```

### Toast 通知规范

```
位置：页面右上角
时长：成功 3s / 错误 5s / 信息 4s
样式：
  ✅ 成功：绿色图标 + 文字
  ❌ 错误：红色图标 + 文字 + 可展开详情
  ℹ️ 信息：蓝色图标 + 文字
  ⚠️ 警告：橙色图标 + 文字

动画：从右侧滑入，停留后滑出
```

## 九、移动端适配交互（参考 WebOsmotic）

虽然本项目是 PC 端，但以下模式在窄屏/响应式场景下有用：

### 优先列 + 横向滚动

```
保持 2 个关键字段始终可见，次要字段允许横向滚动
固定行标签在左侧，主操作在右侧
```

### 卡片堆叠

```
移动断点下，表格行转为独立卡片
主标识成为卡片标题
其余字段变为 key-value 堆叠
```

### 行内展开

```
点击行展开更多字段
使用 key-value 布局
底部固定操作栏
```
