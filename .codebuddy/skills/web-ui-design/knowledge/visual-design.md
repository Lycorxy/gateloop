# 视觉设计速查（Phase 5 必读）

> 设计感 = 概念先行 + 有主见的系统决策 + 可感知的记忆点。
> 本文件是 Phase 5 视觉设计的选型库：风格谱系 → 色彩 → 字体 → 背景 → 签名元素。

## 1. 设计概念模板（designConcept）

```
keywords: [3-5 个风格关键词]（要具体到能指导决策，如"编辑感/暖调/锐利"，禁"现代简洁"）
mood: 一句话气质（"安静而有分量，像装帧讲究的杂志"）
reference: 参照系（对标产品/风格名 + 借鉴什么 + 差异化什么）
```

## 2. 风格谱系（选一个主风格 + 声明理由，可混合但要有主次）

| 风格 | 关键词 | 适用 | 视觉特征 |
|---|---|---|---|
| 极简瑞士 | 网格/克制/留白 | B端工具/文档 | 强网格、无衬线、黑白灰+单主色 |
| 编辑杂志 | 编辑感/层级/衬线 | 内容页/官网 | 衬线大标题、栏式排版、首字下沉 |
| 暗色科技 | 深/发光/锐利 | 开发者工具/监控 | 深底、霓虹强调色、等宽字体、细边框 |
| 柔和圆润 | 圆/软/亲和 | C端/教育/母婴 | 大圆角、柔和渐变、插画、暖色 |
| 新粗野主义 | 粗/撞色/直给 | 创意站/活动页 | 粗边框、硬阴影、高饱和撞色 |
| 玻璃拟态 | 透/层次/光 | 音乐/媒体 | 半透明层、backdrop-blur（局部可用，禁全局） |
| 数据可视化 | 密度/对比/精准 | 仪表盘/BI | 等宽数字、图表色板、紧凑网格 |
| 纸质印刷 | 纸感/油墨/温度 | 阅读/文化 | 米白底、衬线、噪点纹理 |
| 工业硬朗 | 金属/结构/秩序 | 制造/物流 | 直角、警示色点缀、粗字重 |
| 日式侘寂 | 素/间隙/呼吸 | 品牌站 | 大留白、低饱和、竖排点缀 |
| 复古像素 | 8bit/怀旧/游戏 | 游戏站/活动 | 像素字体、扫描线、有限色板 |
| 渐变流体 | 流动/光感/未来 | AI/营销页 | 大渐变、blob 形状、光斑（禁 AI 紫渐变套路） |

## 3. 色彩系统速查

```
60-30-10：中性底 60% / 次级面 30% / 主色 10%
色环关系：类比（相邻，和谐）/ 三角（等距，活泼）/ 互补（对角，冲击）
中性阶：50 页面底 / 100 卡片 / 200 边框 / 600 次文字 / 900 主文字（≥5 档）
主色生成色阶：主色 + hover 深 10% + active 深 20% + 浅底 tint（选中背景）
语义色独立：success/warning/error/info 不与主色混用
dark 模式：色阶翻转（页面底 900、文字 50），主色提亮保对比度
```

## 4. 字族配对表（display + body + mono，声明理由）

| 场景 | display | body | mono |
|---|---|---|---|
| 现代工具 | Inter/HarmonyOS Sans | 同族 | JetBrains Mono |
| 编辑感 | Noto Serif SC/思源宋 | Noto Sans SC | IBM Plex Mono |
| 中文亲和 | 站酷系列/圆体 | 苹方/思源黑 | SF Mono |
| 开发者 | Geist/JetBrains Mono | Inter | 同 display |
选型理由模板："display 用 X 因为____（气质匹配概念），body 用 Y 因为____（可读性/中文回退）"。
字号阶梯（1.25 modular）：12/14/16/20/24/32（页面级）；行高正文 1.5-1.7、标题 1.2-1.3。

## 5. 背景质感手法（页面背景禁裸奔，按概念选 1-2 种）

```
浅色系：米白底(#FAFAF7) / 极浅渐变 wash / 噪点纹理(2-3% 透明度) / 细网格线 / 大圆角色块分区
深色系：深蓝黑底(#0A0E14) / 径向光晕 / 扫描线 / 发光边框渐变
装饰性：几何形状穿插(大圆/斜切) / 品牌色 2-5% 透明度色块 / 角落插画/图案
分区层次：底色差(50 vs 100) + 边框(200) + 阴影第一档，三选二以上
```

## 6. 签名元素案例库（至少选 1 个，低成本高辨识优先）

- 栏目标题：左侧 3px 主色竖条 + 等宽序号（01/02/03）
- 数据页：所有数字用 mono + tabular-nums，变化时数字滚动动效
- 空态：一组统一风格的极简线稿插画（非通用图标库拼凑）
- 交互：主按钮 hover 时箭头位移动效；卡片 hover 时边框渐变扫过
- 色彩：主色只出现在"选中态 + 一个固定装饰位"，形成节奏
- 排版：每区标题统一用小型大写字母 + 字距拉宽（英文场景）
- 形状：贯穿全站的斜切角/圆点阵/波浪分隔线

## 7. 视觉决策自检（Phase 5 产出前）

```
□ 设计概念的每个关键词都能指出对应的视觉落点？
□ 拿掉 logo 后，这个页面还能被认出是"这个产品"？（签名元素有效性）
□ 色彩/字体/背景 任何一项是"没提就没做"的裸奔状态？
□ 三张不同页面放一起，像同一个设计系统？（一致性）
□ 对照 RULE 审美反模式 10 条逐条过关？
```
