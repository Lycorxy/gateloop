## 核心设计理念

```
1. 先读Brief → 推断设计方向 → 设置三旋钮
2. 选择设计系统（官方优先，审美其次）
3. 按Token系统生成（禁止硬编码）
4. 覆盖全状态（Loading/Empty/Error/Success）
5. 克制→单一主色，单一动作，单一焦点
6. 反AI默认→识别并避免AI模板化设计
```
