## 🎯 设计流程速查

```
0. 设计读 → 明确页面类型/用户/约束
1. 信息分级 → P0/P1/P2/P3
2. 方案对比 → 至少 2 方案 + 评分表
3. 交互论证 → 每个节点说明选择理由
4. 6 项检测 → 全过才产出代码
5. 代码审计 → 间距/颜色/交互/布局/体验
```

## 📐 间距系统（4px 网格）

| Token | 值 | 使用场景 |
|-------|-----|---------|
| `--space-1` | 4px | 图标与文字间距、紧密元素 |
| `--space-2` | 8px | 组件内部元素间距 |
| `--space-3` | 12px | 相关元素组间距 |
| `--space-4` | 16px | 表单项间距、列表项间距 |
| `--space-5` | 20px | 小分组间距 |
| `--space-6` | 24px | 卡片内边距、组件间间距 |
| `--space-8` | 32px | 区域间间距 |
| `--space-10` | 40px | 大区域间距 |
| `--space-12` | 48px | 页面级分隔 |
| `--space-16` | 64px | 最大分隔 |

### 间距层级公式

```
组件内部: 4-8px
组件间: 12-24px
分组间: 24-32px
区域间: 32-48px
页面 padding: 24-32px
```

## 🎨 色彩系统

### 使用比例

```
中性色（灰/白/背景）: 80-85%
主色（品牌/CTA/选中）: 3-5%
语义色（成功/警告/错误）: 按需（≤ 5%）
辅助色（图表/标签）: 按需（≤ 10%）
```

### 中性色阶梯（参考）

```css
--neutral-01: #fafafa; /* 页面背景 */
--neutral-02: #f5f5f5; /* 卡片/区域背景 */
--neutral-03: #e8e8e8; /* 边框/分割线 */
--neutral-04: #d4d4d4; /* 禁用态 */
--neutral-05: #a3a3a3; /* 占位符/辅助文字 */
--neutral-06: #737373; /* 次要文字 */
--neutral-07: #525252; /* 正文 */
--neutral-08: #262626; /* 标题 */
--neutral-09: #171717; /* 最深色 */
```

## 📋 组件选择速查

### 数据展示

```
少量 KPI → Stat Card（数字 + 标签 + 趋势箭头）
列表数据 → Table（可排序/过滤/分页）
时间线 → Timeline / Feed
状态概览 → Badge + Color Dot
层级数据 → Tree / Nested List
```

### 用户操作

```
单选（≤ 4 项） → Radio Group
单选（> 4 项） → Select
多选（≤ 6 项） → Checkbox Group
多选（> 6 项） → Multi-Select / Transfer
开关 → Switch（立即生效）/ Checkbox（需提交）
范围 → Slider / Range Input
```

### 导航

```
一级导航（≤ 8 项） → 顶栏 / 侧栏
二级导航 → Tab / 侧栏子菜单
三级导航 → 面包屑 + 内容区 Tab
跨页跳转 → Link / 面包屑
页内跳转 → Anchor / ScrollSpy
```

## ⚡ 布局决策速查表

| 内容特征 | 推荐布局 | 关键参数 |
|---------|---------|---------|
| 操作面板（工具型） | 固定侧栏/顶栏 + 主区域 | 侧栏 240-280px |
| 数据看板 | Grid(2-4 列) + 自适应 | gap: 16-24px |
| 列表管理 | 顶部筛选 + 表格 + 分页 | 筛选栏高 48-56px |
| 详情页 | 主内容 + 右侧属性栏 | 主区 60-70%，属性 30-40% |
| 表单页 | 居中单列 / 双列 | 最大宽 640-800px |
| 设置页 | 左侧导航 + 右侧表单 | 导航 200px |

## 🚨 自检清单（每次产出前过一遍）

```
□ 我能说出这个设计的"记忆点"是什么吗？
□ 我能解释每个布局选择的理由吗？
□ 间距全部是 4 的倍数吗？
□ 颜色全部来自 Token 吗？
□ P0 信息首屏可见吗？
□ 高频操作 ≤ 2 步吗？
□ 空态/加载态/错误态有处理吗？
□ 没有使用 AI 默认审美吗？
```
