# 触发示例

## 正向（必须触发）

1. 「帮我给这个项目接入流水线，然后发布到测试环境」→ 场景 A（接入）+ 场景 B（发布测试）
2. 「代码提交错了，帮我把上一步的操作回退掉」→ 场景 D（回退，危险操作需确认）
3. 「开发完了，创建一个 1.3.0 的版本并提 MR」→ 场景 A（版本发布）
4. 「flowcli 没装，先帮我装一下，再启动流水线」→ Step 0 环境检测（安装）+ 发布测试场景

## 负向（不得触发）

1. 「git rebase 和 git merge 有什么区别？」→ 概念咨询，非 flowcli 操作
2. 「帮我在 GitHub 上创建一个 PR」→ 非工蜂平台
3. 「把生产环境的流水线跑一下」→ 生产环境发布被工具禁止，仅引导手动操作（不进入执行流程）
