# 表格设计

---

## 一、表格使用决策

### 何时使用表格

```
✅ 数据量 > 10 条
✅ 需要多字段对比
✅ 需要排序/筛选/搜索
✅ 需要批量操作
✅ 数据结构一致（每行字段相同）

❌ 数据 < 5 条 → 用 Card/List
❌ 主要展示图片 → 用 Gallery/Grid
❌ 时间线叙事 → 用 Timeline
❌ 层级关系 → 用 Tree
```

## 二、表格布局规范

### 列宽分配

| 列类型 | 最小宽 | 推荐宽 | 对齐 |
|--------|-------|--------|------|
| 复选框 | 40px | 40px | 居中 |
| 序号 | 48px | 56px | 居中 |
| 文本短 | 80px | 120px | 左 |
| 文本长 | 120px | 200-300px | 左 |
| 数字 | 60px | 80-120px | 右 |
| 日期 | 100px | 140px | 左 |
| 状态 | 60px | 80-100px | 左/居中 |
| 操作 | 80px | 120-160px | 右 |

### 行高标准

| 密度 | 行高 | 适用场景 |
|------|------|---------|
| 紧凑 | 36px | 数据密集、专业用户 |
| 标准 | 44px | 通用场景（默认） |
| 宽松 | 56px | 含头像/图片/多行文本 |

## 三、表格交互设计

### 行操作策略选择

| 策略 | 适用 | 优点 | 缺点 |
|------|------|------|------|
| **末列固定** | 操作 ≤ 3 个 | 始终可见 | 占列宽 |
| **Hover 显示** | 操作 > 3 个 | 行干净 | 移动端不友好 |
| **更多按钮** | 操作 > 3 个 | 节省空间 | 多一步点击 |
| **行点击** | 主操作只有 1 个（查看详情） | 高效 | 不适合多操作 |

### 表格筛选最佳实践

```
1. 搜索框：始终可见，宽 200-300px
2. 快捷筛选：Tab 或 Segmented（如"全部/未读/已读"）
3. 高级筛选：Dropdown 或侧边 Filter Panel
4. 已选筛选：Tag 形式展示，可单个移除
5. 清除所有：一键重置筛选条件
```

### 分页 vs 无限滚动

| 因素 | 分页 | 无限滚动 |
|------|------|---------|
| 数据量 | > 50 条 | ≤ 100 条 |
| 用户目标 | 定向查找 | 浏览探索 |
| SEO需求 | 有 | 无 |
| 性能 | 稳定 | 需虚拟化 |
| 定位 | 可分享 URL | 难以定位 |

## 四、表格样式规范

### 行样式

```css
/* 默认行 */
.table-row {
  height: 44px;
  border-bottom: 1px solid var(--neutral-03);
}

/* Hover */
.table-row:hover {
  background: var(--neutral-01);
}

/* 选中 */
.table-row.selected {
  background: var(--primary-lighter);
}

/* 展开行 */
.table-row.expanded {
  border-bottom: none;
}
.table-row-detail {
  background: var(--neutral-01);
  padding: 16px 16px 16px 56px;
}
```

### 表头样式

```css
.table-header {
  height: 44px;
  background: var(--neutral-02);
  font-size: 12px;
  font-weight: 600;
  color: var(--neutral-06);
  text-transform: uppercase;
  letter-spacing: 0.5px;
  position: sticky;
  top: 0;
  z-index: 1;
}
```

## 五、表格高级模式

### 可展开行

```
┌──┬────────────────────────────────────────┐
│ ▶│ Item 1    Status: Active    2024-01-15 │
├──┼────────────────────────────────────────┤
│ ▼│ Item 2    Status: Done      2024-01-14 │
│  │ ┌──────────────────────────────────────┐│
│  │ │ 详情内容：子表格/描述/操作            ││
│  │ └──────────────────────────────────────┘│
├──┼────────────────────────────────────────┤
│ ▶│ Item 3    Status: Pending   2024-01-13 │
└──┴────────────────────────────────────────┘
```

### 内联编辑

```
触发方式：双击单元格 / 点击编辑图标
编辑态：Input 替换文本，自动 focus
确认：回车 / 失焦保存
取消：Esc 回退
反馈：保存成功闪烁绿色 200ms
```

### 批量操作

```
1. 用户勾选 → 顶部出现批量操作栏（浮动/替换表头）
2. 操作栏内容：已选 N 项 | [删除] [标记为...] [导出] | [取消]
3. 全选逻辑：当前页全选 / 跨页全选（需说明）
4. 破坏性批量操作必须二次确认
```

## 六、表格反模式

| 反模式 | 问题 | 修复 |
|--------|------|------|
| 列太多横向滚动 | 用户看不全 | 固定关键列 + 列可配置 |
| 操作太多一行放不下 | 按钮挤在一起 | 更多按钮收起 / hover 展开 |
| 无空态 | 用户不知道为什么没数据 | 友好空态引导 |
| 数字无格式化 | 1234567 不好读 | 千分位 1,234,567 |
| 无 loading | 数据加载时空白 | Skeleton 行 |
| 分页数没选择 | 默认 10 条太少 | 支持 10/20/50/100 切换 |
