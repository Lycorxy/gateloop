# 组件规范

---

## 一、按钮系统

### 按钮层级（严格遵循）

| 层级 | 样式 | 使用场景 | 限制 |
|------|------|---------|------|
| **Primary** | 实心主色填充 | 页面核心 CTA | 每个视图 ≤ 1 个 |
| **Secondary** | 边框 + 透明背景 | 次要操作 | 不限 |
| **Tertiary** | 纯文字 + hover 背景 | 辅助/取消 | 不限 |
| **Danger** | 红色实心/边框 | 删除/破坏性 | 仅破坏操作 |
| **Ghost** | 无边框无背景 | 紧凑工具栏图标按钮 | 不限 |

**规则**：
- 一个视图中 Primary 按钮 **最多 1 个**
- 操作栏排列：右侧 Primary → Secondary → Tertiary（从右到左重要性递减）
- 按钮内文字 ≤ 4 字（中文）/ 2 词（英文）

### 按钮尺寸

| 尺寸 | 高度 | padding-x | 字号 | 圆角 | 使用场景 |
|------|------|-----------|------|------|---------|
| SM | 28px | 12px | 12px | 4px | 表格行内/紧凑工具栏 |
| MD | 36px | 16px | 14px | 6px | 标准操作（默认） |
| LG | 44px | 20px | 16px | 8px | Hero CTA/表单提交 |

## 二、输入框

### 状态样式

| 状态 | 边框 | 背景 | 阴影 |
|------|------|------|------|
| Default | neutral-03 | neutral-00 | none |
| Hover | neutral-04 | neutral-00 | none |
| Focus | primary | neutral-00 | 0 0 0 2px primary/20% |
| Error | error | error-bg | 0 0 0 2px error/20% |
| Disabled | neutral-03 | neutral-02 | none |
| Readonly | none | neutral-02 | none |

### 输入框规范

```
Label 位于输入框上方（非浮动标签，浮动标签对辅助工具不友好）
Label 到 Input 间距：4-8px
Help text 在 Input 下方：4px
Error message 替换 help text，颜色 error
Placeholder 颜色：neutral-05，语气为示例非指令
```

## 三、卡片

### 卡片分类

| 类型 | 样式 | 交互 | 使用 |
|------|------|------|------|
| **展示卡片** | border + 轻 shadow | 无/hover 高亮 | 数据概览 |
| **操作卡片** | border + 可点击 | 整卡可点 + hover shadow | 导航入口 |
| **选择卡片** | border + 选中主色边 | 点击选中 | 选择器 |
| **容器卡片** | 无 border/轻背景 | 无交互 | 内容分组 |

### 卡片规范

```
内边距：16-24px（根据内容密度）
圆角：8-12px
最小高度：不设（由内容决定）
卡片间距：16-24px
卡片内元素间距：8-16px
```

## 四、表格（核心组件）

### 表格设计原则

1. **行高**：44px（标准）/ 36px（紧凑）/ 56px（宽松）
2. **列对齐**：
   - 文字/状态：左对齐
   - 数字/金额：右对齐
   - 操作按钮：右对齐
   - 复选框：居中
3. **固定列**：操作列 + 第一标识列可固定
4. **行 hover**：浅灰背景 neutral-01/02
5. **斑马纹**：可选，仅在行数 > 10 时考虑

### 表格交互

| 交互 | 实现 | 何时使用 |
|------|------|---------|
| 排序 | 列头点击 ↕ | 有对比需求的数字/日期列 |
| 筛选 | 列头 dropdown / 顶部筛选栏 | 数据量 > 50 行 |
| 行选择 | 复选框 + 顶部批量操作栏 | 需要批量操作 |
| 行展开 | 点击箭头展开详情 | 数据有子级/详情 |
| 行操作 | hover 显示操作按钮 / 末列固定 | 每行有 2-4 个操作 |
| 内联编辑 | 双击单元格 / 点击编辑图标 | 高频修改场景 |
| 拖拽排序 | 左侧拖拽手柄 | 手动排序 |

## 五、Badge/Tag

### 语义颜色

| 语义 | 背景 | 文字 | 使用场景 |
|------|------|------|---------|
| 成功 | success-bg | success | 已完成/已通过 |
| 警告 | warning-bg | warning | 待处理/审核中 |
| 错误 | error-bg | error | 失败/拒绝 |
| 信息 | info-bg | info | 新/标注 |
| 中性 | neutral-02 | neutral-07 | 默认/草稿 |

### Badge 规范

```
高度：20-24px
内边距：4-8px 水平
圆角：4px（方形）或 9999px（圆弧）
字号：12px
字重：500
禁止：多于 5 种颜色同时出现
```

## 六、Tooltip / Popover

### 何时使用

| 组件 | 触发 | 内容 | 位置 |
|------|------|------|------|
| **Tooltip** | Hover（延迟 300ms） | 纯文字说明 ≤ 2 行 | 元素上方/下方 |
| **Popover** | Click | 小型交互内容 | 元素附近 |

### 禁忌
- ❌ Tooltip 里放可点击内容
- ❌ 重要信息只在 Tooltip 里
- ❌ Tooltip 触发延迟 > 500ms
- ❌ Popover 嵌套 Popover

## 七、导航组件

### 侧边栏

```
展开宽度：240px
收起宽度：64px
菜单项高度：40px
菜单项 padding-left：按层级递增 12px
选中态：主色背景 8% + 主色左边框 3px
图标尺寸：20px
图标到文字间距：12px
分组标题：12px，neutral-05，uppercase
```

### 面包屑

```
分隔符：/ 或 >（neutral-05）
当前项：neutral-08，不可点击
历史项：primary，可点击
最大显示：4 级（超出中间折叠 ...）
```

### Tab

```
Tab 项间距：0（紧邻）或 4-8px
活跃指示：底部 2px 主色线 / 背景高亮
Tab 高度：40-48px
字号：14px
活跃字重：600
非活跃色：neutral-06
最大 Tab 数：5（超出用 Select 或 overflow 滚动）
```

## 八、组件组合模式

### 搜索 + 筛选 + 操作栏

```
┌─────────────────────────────────────────────────┐
│ [🔍 搜索关键词...]  [状态 ▼] [类型 ▼]  [+ 新建] │
└─────────────────────────────────────────────────┘
```

- 搜索框占 200-300px
- 筛选项左对齐
- 操作按钮右对齐
- 高度：48px
- 底部间距到表格：16px

### 统计卡片组

```
┌──────────┐ ┌──────────┐ ┌──────────┐ ┌──────────┐
│ 总量      │ │ 今日新增  │ │ 活跃数    │ │ 完成率    │
│ 12,345   │ │ +128 ↑   │ │ 4,567    │ │ 87.3%    │
│ +12.5%   │ │ vs 昨日   │ │ -2.1%    │ │ 目标 90% │
└──────────┘ └──────────┘ └──────────┘ └──────────┘
```

- 卡片等宽 Grid 布局
- 主数字：24-28px, bold
- 次要信息：12px, neutral-06
- 趋势标识：绿色上升/红色下降
- 间距：16px
