# 04 — 布局原则

---

## 一、对齐系统

### 基线网格

```
所有元素基于 4px 网格对齐。

允许的间距值：4, 8, 12, 16, 20, 24, 28, 32, 40, 48, 64, 80, 96
禁止的值：5, 7, 9, 13, 15, 17, 19, 22, 25, 30, 35, 50, 55, 60, 70, 90, 100
```

### 对齐基线

一个页面最多使用 3 种垂直对齐基线：
```
基线 1: 内容区左边缘（所有标题/段落起点）
基线 2: 表格/表单的值列起点
基线 3: 右侧操作/数字列的右边缘

不允许出现第 4 条基线（会显得凌乱）
```

## 二、间距节奏

### 亲密性法则

```
间距传达关系：
- 紧密 (4-8px) → 这些元素属于同一个组
- 标准 (12-16px) → 这些是同级的不同条目
- 分隔 (24-32px) → 这些是不同的区域/分组
- 远离 (40-64px) → 这些是完全独立的板块

原则：相关的东西靠近，不相关的东西远离
```

### 间距层级公式

```
组件内部 < 组件间 < 分组间 < 区域间

具体值参考：
组件内部: 4-8px (label↔input, icon↔text)
组件间:   12-16px (input↔input, button↔button)
分组间:   20-32px (form section↔section)
区域间:   32-48px (header↔content, content↔footer)
页面边距: 24-32px

检测方法：提取代码中所有 margin/padding/gap，
验证是否 strictly 遵循: 内部 < 组件间 < 分组间 < 区域间
```

## 三、空间分配

### 内容区宽度限制

| 内容类型 | max-width | 原因 |
|---------|-----------|------|
| 阅读文本 | 640-720px | 每行 45-75 字符最佳 |
| 表单 | 480-640px | 字段不需要太宽 |
| 表格 | 100%（容器宽） | 数据需要空间 |
| 看板卡片 | 无限制（Grid） | 响应式自适应 |
| 代码块 | 100%（容器宽） | 不换行 |

### 黄金分割在布局中的应用

```
主内容:侧栏 ≈ 62:38 或 70:30

常见分割：
- 侧栏 240px + 主内容 auto → 适合导航型
- 主内容 60% + 属性栏 40% → 适合 Master-Detail
- 主内容 70% + 属性栏 30% → 适合宽屏
```

## 四、留白的艺术

### 留白不是浪费空间

```
留白的功能：
1. 分组 — 间距传达元素关系
2. 呼吸 — 防止信息过载
3. 焦点 — 大留白包围的元素最突出
4. 节奏 — 疏密交替产生视觉韵律
```

### 留白的节奏

```
❌ 均匀留白（无节奏）：
┌────────────────────────┐
│                        │
│  Content A             │
│                        │
│  Content B             │
│                        │
│  Content C             │
│                        │
└────────────────────────┘

✅ 有节奏的留白（疏密交替）：
┌────────────────────────┐
│                        │ ← 小留白
│  Title (大)            │
│                        │ ← 紧密
│  Description           │
│                        │
│                        │ ← 大留白（分隔）
│  Content Section       │
│  ├─ item 1            │ ← 紧密
│  ├─ item 2            │
│  └─ item 3            │
│                        │
│                        │ ← 大留白（分隔）
│  Action Area           │
└────────────────────────┘
```

## 五、响应式策略

### 断点设计原则

```
不是"在每个断点重新设计"，而是"设计一个弹性布局 + 关键调整"：

1. Desktop-first（管理后台通常桌面优先）
2. 内容先，布局后（内容决定布局，不是反过来）
3. 用 max-width + margin auto 居中
4. 侧栏用 overlay/collapse 处理小屏
5. 网格用 auto-fit/auto-fill 自然响应
```

### 常见响应式模式

| 模式 | Desktop | Tablet | Mobile |
|------|---------|--------|--------|
| 侧栏导航 | 展开 240px | 折叠 64px | Overlay |
| 表格 | 完整列 | 隐藏次要列 | 卡片化 |
| Grid 4列 | 4列 | 2列 | 1列 |
| Master-Detail | 并排 | 并排(60/40) | 堆叠 |
| 操作栏 | 水平 | 水平 | 收入更多 |
